# Surface brief: 進入頁 (templates/home.html)

Mode: Experience

沿用讀經頁的直接契約（見 templates-read-html.md 的 Direction contract），本頁只記錄這個畫面自己的決定。

- 進場儀式：使用者明確要求動畫要好看、不要簡化。入口是一張線稿剖面，線一筆筆畫出房子，晨光從窗口斜射到桌上的書（約 2.4 秒）。每個瀏覽工作階段只播一次；整個畫面從第 0 秒起可點擊進入（點任何地方、Enter、空白鍵）；`prefers-reduced-motion: reduce` 時直接顯示完成畫面。仍禁止星點永久閃爍與呼吸提示。
- 選書流程：存檔選單 → 新舊約 → 書卷 → 章節，改為同一張剖面上逐層展開，不再是整頁淡入淡出切換；返回鈕固定在拇指區。
- 進入頁色調可比讀經頁暗，但仍使用同一組炭灰、日光金、陰影藍。
